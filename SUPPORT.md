# Support

For ordinary defects and proposals, use the repository issue forms. Include the
revision, Python version, operating system, exact sanitized command, expected
behavior, and sanitized output.

For vulnerabilities, use a private GitHub security advisory as described in
`SECURITY.md`.

Never attach credentials, client vaults, raw run directories, local account
identifiers, or unredacted logs. A minimal reproduction is more useful than a
large private capture.
