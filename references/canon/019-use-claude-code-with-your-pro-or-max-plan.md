# 019. Use Claude Code with your Pro or Max plan

## What It Says

- Pro and Max users authenticate Claude Code with the same Claude credentials used for their subscription
- Claude Code activity on those plans counts against shared Claude and Claude Code usage limits
- API-key authentication instead uses API billing and can incur API charges
