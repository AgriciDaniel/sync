# Sync v1.0.0

First release of Sync, the evidence-gated local orchestration harness and
Obsidian brain for Claude and Codex council workflows.

## Included

- Role-based routing across declared billing pools, with explicit authorization
  boundaries and current-headroom requirements for capacity claims.
- Artifact-mediated run directories, bounded Codex dispatch, and typed result
  handling.
- Network-isolated, argv-only verification gates with redacted evidence and
  fingerprint-bound verdicts.
- Outcome recording, measurement, and policy-evolution controls that refuse to
  treat model judgment as verification.
- Transactional installers with rollback protection.
- A source-cited template brain, deterministic sample vault, and a
  fingerprint-verified Sync-run importer.
- Reproducible release archives with SHA-256 checksums and deterministic
  release-content scanning.

## Verification

This release is backed by the repository's market-ready audit, source-bound
acceptance suite, reproducible package checks, secret scanning, and hosted CI
for the tagged revision.

The privacy review found no live credential pattern, private key, local home
path, or personal email in reachable Git history. The source tree contains one
reserved non-deliverable test address, `sync-test@example.invalid`, and the Git
author uses GitHub's noreply address.

## Important boundaries

Sync is local-first, operator-controlled infrastructure. It does not authorize
commits, pushes, publication, deployment, spending, account changes, or other
external actions. It makes no claim of measured productivity or capacity gains
without a recorded baseline and outcome evidence.

This release is proprietary. Repository access does not grant redistribution
rights. Public visibility, if approved later, is a separate owner decision.
