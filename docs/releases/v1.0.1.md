# Sync v1.0.1

Sync now introduces itself more directly and uses the supplied Claude and Codex
marks in its council visual.

## Changed

- Replaced the abstract lane symbols with the supplied vendor marks while
  preserving the original Sync composition.
- Rewrote the README opening around the product's core contract: route work by
  role, share context on disk, and accept results only after commands pass.
- Added source-asset provenance and clarified that the marks remain subject to
  their owners' trademark and brand terms.

## Verification

This release is backed by the repository's source-bound market-ready acceptance
suite, release-content scanning, reproducible package checks, and hosted CI for
the tagged revision.

## Important boundaries

This is a presentation and documentation release. It does not change Sync's
routing, execution, verification, or authorization behavior. Sync remains
local-first, operator-controlled, proprietary software. Use of the vendor marks
does not imply partnership, sponsorship, or endorsement.
