# Using Codex with your ChatGPT plan

## What It Says

- Codex is included across ChatGPT plans, with plan-dependent limits
- Codex, ChatGPT Work, ChatGPT for Excel, and Workspace Agents draw from the same agentic usage and credit pool where available
- Task usage varies with task size and complexity, model, and execution location
