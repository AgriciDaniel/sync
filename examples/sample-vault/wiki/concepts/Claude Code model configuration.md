# Claude Code model configuration

## What It Says

- Claude Code documents best as the most capable available model alias, currently equivalent to opus
- The sonnet and opus aliases track the recommended current versions for the active provider and can change over time
- Effort is selectable and lower effort trades depth for speed and usage
